# synchro_video_Fcihier
# Pour exécuter ce pipeline il faut appeler la fonction synchronisation.py et lui doner en arguments :
# une vidéo et un fichier .txt avec séparateur \t.
```python synchronisation.py chemin_video/ chemin_fichier.txt/ ```

# Le script `run_synchro_batch.sh` permet de faire la synchronisation des vidéos segmentées qui sont dans :
# `Bureau/videos` avec les fichiers .txt qui sont dans `Bureau/fichiers`.
# Les résultats sont stockés dans `resultat_synchro`.
# Pour l'exécuter on se place dans le dossier et on tape : ``` ./run_synchro_batch.sh ```
